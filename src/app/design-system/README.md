# design-system

Tokens de color, set curado de iconos y componentes base. Ver `docs/REQUISITOS.md`
§9.1.

Dos reglas que no se saltan:

- **El color nunca viaja solo.** Todo estado se comunica con color + icono + texto.
- **Nada de hexadecimales sueltos en los componentes.** Todo sale de los tokens.
